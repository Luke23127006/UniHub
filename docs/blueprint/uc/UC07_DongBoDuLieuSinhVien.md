| Section                        | Description                                                                                                                                                                                                                                                                                                                                                                          |
| :----------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Use Case Name**              | UC07 - Đồng Bộ Dữ Liệu Sinh Viên Từ CSV                                                                                                                                                                                                                                                                                                                                              |
| **Initial assumption**         | Hệ thống cũ của trường đã xuất tự động file CSV danh sách sinh viên vào thư mục chia sẻ hoặc server FTP vào ban đêm.                                                                                                                                                                                                                                                                 |
| **Normal**                     | 1. Cron job của hệ thống UniHub tự kích hoạt tiến trình đọc file CSV theo thời gian định kỳ hàng đêm.<br>2. Hệ thống tải về và tiến hành phân tích (parse) từng dòng dữ liệu.<br>3. Hệ thống xác thực định dạng và độ toàn vẹn của dữ liệu sinh viên trong file.<br>4. Hệ thống dùng kỹ thuật Upsert để cập nhật dữ liệu sinh viên có sẵn hoặc thêm mới sinh viên vào cơ sở dữ liệu. |
| **What can go wrong**          | - Không tìm thấy file CSV: Hệ thống ghi log cảnh báo và có thể gửi email thông báo cho kỹ thuật viên.<br>- Một vài dòng trong file bị lỗi định dạng hoặc dữ liệu rác: Hệ thống tự động bỏ qua (skip) dòng lỗi đó, ghi log lại các lỗi và tiếp tục xử lý các dòng dữ liệu chuẩn còn lại.                                                                                              |
| **Other activities**           | Toàn bộ quá trình đọc file và cập nhật database được chạy ngầm, chia thành các lô nhỏ (batch processing) để không ảnh hưởng tải hoạt động chung của toàn bộ hệ thống.                                                                                                                                                                                                                |
| **System state on completion** | Bảng danh sách sinh viên nội bộ trong hệ thống UniHub được cập nhật và đồng bộ theo đúng thông tin mới nhất từ nhà trường, cho phép sinh viên đăng nhập và đăng ký hợp lệ.                                                                                                                                                                                                           |
